### Write a short paragraph about this dataset

This dataset contains information about subway entrances and exits in
NYC. The variables include line, station name, station latitude and
longitude, routes served, entry, vending, entrance type, and ADA
compliance. I cleaned the column names, kept the required variables, and
changed `entry` from YES/NO to TRUE/FALSE. The cleaned dataset has 1868
rows and 19 columns. These data are not fully tidy because route names
are stored in separate columns, from `route1` to `route11`.

### Reformat data and answer

``` r
NY_transit_tidy_df =
  NY_transit_df |>
  mutate(
    across(route1:route11, as.character)
  ) |>
  pivot_longer(
    cols = route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name",
    values_drop_na = TRUE
  ) |>
  mutate(
    route_number = as.integer(route_number)
  )
```
